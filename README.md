# PathForge-AI

PathForge-AI is an AI-powered career and learning roadmap platform designed to help students identify skill gaps, discover learning paths, and build a structured roadmap toward their goals.

## Problem Statement

Many students struggle to understand:

- What skills they currently have
- Which skills are missing for their target career
- What should be learned next
- How to create a step-by-step roadmap

PathForge-AI solves this problem by providing personalized guidance and recommendations.

## Features

- AI-powered career guidance
- Skill gap analysis
- Personalized learning roadmap
- User-friendly dashboard
- Responsive design
- Modern and interactive UI

## Installation

Clone the repository:

```bash
git clone https://github.com/rahulthakur2026/PathForge-AI.git
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
